Elsa 的 AI LINE 貼圖創作心得網頁

【打開方式】解壓縮後，雙擊 index.html 即可在瀏覽器查看（請保持資料夾結構不變）。

【如何補上內容】
1. 用記事本或 VS Code 開啟 index.html。
2. 搜尋「【請」，所有黃色螢光標記的待補內容都在這裡，直接改成你的文字，並刪掉【】。
3. 全螢幕貼圖：把截圖放進 images 資料夾，將 index.html 中「在這裡放全螢幕貼圖」那個 <div class="slot"> 換成 <img src="images/你的檔名.jpg" alt="全螢幕貼圖">。

【上線】
- GitHub Pages：建立儲存庫，把整個資料夾內容上傳，到 Settings > Pages 選 main 分支即可。
- Google Sites 不能直接上傳整包網頁，請改用 GitHub Pages，或沿用先前的版面藍圖手動製作。
